# 문장 연습실

고등학교 국어 '문장 성분과 문장의 짜임' 수업용 프로그램입니다.
학생마다 문장 성분 조건, 문장의 짜임 조건, 공익광고 주제가 무작위로 주어지고, 학생이 쓴 문장의 **문법 조건**(문장 성분, 문장의 짜임, 완결된 한 문장)을 AI가 판정해서 고칠 부분을 알려 줍니다. **공익광고 주제와 내용이 맞는지는 AI가 아니라 선생님이 판단**하고, 학생에게 피드백도 남길 수 있습니다. 선생님은 반별 명단을 미리 넣어 두고 학생별 기록을 누적해서 볼 수 있습니다.

## 1. 준비물

- 선생님 컴퓨터(Windows)에 **Node.js** 설치: https://nodejs.org 에서 LTS 버전을 받아 설치하세요. (설치할 때는 기본값 그대로 '다음'만 누르면 됩니다.)
- **API 키**: Claude Console에서 발급합니다. AI 판정은 API 사용량만큼 요금이 나옵니다. 안내: https://docs.claude.com
- 학생 기기와 선생님 컴퓨터가 **같은 와이파이(같은 공유기)** 에 연결되어 있어야 합니다.

## 2. 실행

1. 이 폴더의 `start-windows.bat` 을 더블클릭합니다.
2. 처음 실행하면 검은 창에 **교사 비밀번호**와 **학생 접속 주소**가 나옵니다.
3. 윈도우 방화벽 창이 뜨면 **'액세스 허용'** 을 누르세요. (허용하지 않으면 학생들이 접속하지 못합니다.)
4. 선생님 컴퓨터에서 인터넷 브라우저로 `http://localhost:3000/teacher` 를 엽니다. 비밀번호를 입력하세요.
5. **[설정·시험]** 탭에서 API 키를 입력하고 **[연결 시험]** 을 눌러 확인합니다.
6. **[명단 관리]** 탭에서 반별 명단을 붙여 넣습니다.

검은 창을 닫으면 프로그램이 꺼집니다. 수업 동안에는 켜 두세요.

## 3. 명단 넣기

엑셀이나 한글에서 `학번`과 `이름` 두 열을 복사해서 붙여 넣으면 됩니다. 한 줄에 한 명입니다.

```
20301 김하늘
20302 이도윤
20303 박서연
```

- 학번이 5자리(예: 20312 = 2학년 3반 12번)이면 반과 번호가 자동으로 나뉩니다.
- 여러 반을 한꺼번에 붙여 넣어도 됩니다.
- 학번 형식이 다르면 '반 이름' 칸에 반을 직접 적어 주세요.
- 같은 학번을 다시 붙여 넣으면 이름이 갱신됩니다. 기록은 학번을 기준으로 이어서 쌓입니다.

## 4. 수업 진행

1. 선생님 화면 **[현황]** 에 학생 접속 주소와 QR코드가 있습니다. 화면에 띄워 주세요.
2. 학생은 주소로 들어와 **학번과 이름만** 입력하면 입장합니다. (명단에 있는 학생만 들어올 수 있습니다.)
3. 학생은 무작위 조건 3개를 받고 문장을 씁니다. 틀리면 고칠 부분에 밑줄이 그어지고 고치는 방향을 안내받습니다.
   - 오답이 3번 쌓이면(설정에서 바꿀 수 있어요) 예시 문장을 보여 줍니다.
   - 3번 도전하거나 정답을 맞히면 새 조건을 받을 수 있습니다.
4. 선생님은 **[현황]** 에서 접속 중인 학생, 제출 수, 정답률을 실시간으로 봅니다. 학생 이름을 누르면 그 학생의 문장과 피드백을 모두 볼 수 있습니다.
5. **[제출 모아보기]** 에서 '교사 확인 필요' 로 거르면 AI가 확신하지 못한 문장, 판정이 안 된 문장, 학생이 '판정이 이상해요'를 누른 문장만 모아 봅니다. 여기서 **정답/오답으로 직접 고칠 수 있습니다.** 고친 결과가 최종 기록이 됩니다.
6. **주제 판단과 피드백**: [제출 모아보기]의 각 기록 카드 아래에서 `주제 판단`(적절/부적절)을 누르고, 학생에게 보여 줄 피드백을 적어 `피드백 저장`을 누르면 학생 화면에 나타납니다(학생 화면은 15초마다 자동으로 확인합니다). 자주 쓰는 말은 아래 버튼을 눌러 넣을 수 있습니다.
   - 주제 필터를 `주제 확인 필요 (문법 정답 중)`으로 두면 아직 주제를 보지 않은 정답 기록만 모아 볼 수 있습니다. `보이는 기록 모두 '주제 적절'`로 한꺼번에 적절 표시한 뒤 부적절한 것만 골라 바꿀 수도 있습니다.
   - 피드백 유무로도 걸러 볼 수 있고, CSV에는 `주제 판단(교사)`, `교사 피드백` 열이 들어갑니다.
7. 수업이 끝나면 **[현황]** 의 `학생 입장 닫기` 를 눌러 두면 수업 시간 밖에는 들어오지 못합니다.

기록은 수업이 끝나도 사라지지 않고 계속 누적됩니다. 기간(전체 / 오늘 / 최근 7일)과 반으로 걸러 볼 수 있고, `학생별 누적 CSV`, `제출 기록 CSV` 로 엑셀에서 열 수 있게 내려받을 수 있습니다.

## 3-1. 학생별 난이도

`명단 관리`의 현재 명단에서 학생마다 **난이도**를 정할 수 있습니다. 여러 명을 체크한 뒤 `선택한 학생에게 적용`으로 한꺼번에 바꿀 수도 있어요.

- **수업 설정대로**(기본): `설정·시험`의 난이도 설정과 `조건 관리`의 성분 개수 범위를 그대로 따릅니다.
- **하(쉬운 조건)**: 문장의 짜임은 '쉬움' 조건만, 문장 성분은 정해 둔 개수 범위에서 가장 적은 개수로 나옵니다.
- **상(기본 조건)**: 문장의 짜임은 '기본' 조건만, 문장 성분은 가장 많은 개수로 나옵니다.
- 지정한 뒤 **새로 받는 조건부터** 적용되고, 학생 화면에는 난이도가 표시되지 않습니다. 현황판 칸 번호 옆에 '하'·'상'이 작게 보입니다.
- 난이도는 명단 파일에 함께 저장되어, 학생을 다시 등록해도 유지됩니다.

## 4-0. 교사 화면 '현황판'

`현황판` 탭에서는 학생 한 명이 네모 한 칸으로, 한 줄에 6칸씩 반별로 나란히 보입니다. 3초마다 저절로 바뀌므로 수업 중 띄워 두고 한눈에 볼 수 있어요.

- **입력 중(파랑)** 문장을 쓰고 있는 학생. 글 내용은 보내지 않고 글자 수 신호만 받습니다. 제출한 글을 그대로 둔 채로는 입력 중이 아닙니다.
- **확인 대기(노랑)** 제출했지만 아직 선생님 판정이 필요한 문장(AI 없이 쓰는 방식, 또는 AI 판정 오류인 경우 'AI 오류').
- **정답(초록) / 오답·반려(빨강)** 가장 최근 제출의 문법 판정. 오답이면 칸에 도전 횟수(2회, 3회…)가 보여요.
- **접속함(흰색) / 미접속(점선 회색)** 새 조건을 받으면 다시 '접속함'으로 돌아갑니다.
- 칸 모서리의 **주**는 주제 확인 필요, **!** 는 선생님 확인 필요 표시입니다.
- 위쪽 상태 이름을 누르면 그 상태의 칸만 강조되고, 칸을 누르면 그 학생의 제출 기록·판정·피드백 창이 열립니다.

### 자리 배치 옮기기

현황판 위쪽 **[자리 배치 편집]** 을 누르면 칸을 마우스(태블릿은 손가락)로 끌어서 실제 앉아 있는 자리대로 옮길 수 있습니다. 다른 학생 칸 위에 놓으면 두 학생의 자리가 바뀌고, 빈 칸에 놓으면 그 자리로 옮겨 갑니다. 사이사이 빈 칸을 두면 복도나 모둠 사이 간격도 표현할 수 있어요.

- 바꾼 배치는 바로 자동 저장되고(`data/seats.json`), PC와 태블릿이 같은 배치를 봅니다. 반마다 따로 저장됩니다.
- `번호순으로 되돌리기`로 처음 배치로 돌아갈 수 있고, 새로 명단에 들어온 학생은 맨 뒤에 붙습니다.

## 4-1. 포스터 프롬프트 만들기

학생 화면 아래의 **[포스터 프롬프트 만들기]** 에서 완성한 문장(문법 조건을 맞힌 문장, AI 없이 쓰는 방식에서는 선생님이 확인 중인 문장 포함)으로 공익광고 포스터용 프롬프트를 만듭니다.

- 학생은 **그림 스타일, 분위기, 색감, 구도, 포스터 모양, 글씨체와 글자 위치** 등을 버튼으로 고르고, **주제·등장 대상·장면·세부 요청·넣지 말 것**을 직접 쓴 뒤 `프롬프트 만들기`를 누릅니다. 한국어와 English 두 가지 프롬프트가 만들어지고 `복사하기`로 복사할 수 있습니다.
- 프롬프트는 AI 호출 없이 정해진 규칙으로 조립하므로 **비용이 들지 않습니다.** 폭력·선정 표현, 실존 인물, 상표·로고는 항상 '넣지 말아야 할 것'에 들어갑니다.
- 만든 프롬프트는 선생님이 볼 수 있게 저장됩니다. 교사 화면의 **[포스터]** 탭에서 학생별로 보고, 복사하고, 삭제하고, CSV로 내려받을 수 있습니다.
- `[설정·시험]`의 '포스터 프롬프트'를 '닫기'로 하면 학생 화면에서 버튼이 사라집니다(수업 단계에 맞춰 열고 닫을 수 있어요).
- 프롬프트를 붙여 넣을 이미지 생성 도구는 선생님이 정해서 안내해 주세요. 이 프로그램은 이미지를 만들지 않습니다. 이미지 AI는 한글 글씨를 틀리게 그릴 때가 있어 '글자 없이 그림만' 선택지도 넣었습니다.
- 선택지를 고치고 싶으면 `public/poster.js` 맨 위의 `OPTIONS`를 메모장으로 열어 고치세요.

## 4-1b. 학생이 주제 바꾸기

학생 화면의 '공익광고 주제' 줄에서 **[다른 주제로 바꾸기]** 를 열면 선생님이 `조건 관리`에 등록해 둔 주제 목록(끈 주제 제외) 중에서 랜덤으로 나온 것과 다른 주제를 고를 수 있습니다. 직접 입력은 할 수 없습니다. 문장을 제출하기 전까지 바꿀 수 있고, 제출하면 그 조건에서는 고정됩니다.

- 고른 주제는 기록·패들렛 글·포스터 프롬프트에 그대로 쓰이고, 교사 화면 제출 기록에는 '(학생이 고름)'으로 표시됩니다. 주제는 이전처럼 AI가 채점하지 않고 선생님이 판단합니다.
- 주제를 정해진 대로만 쓰게 하려면 `[설정·시험]` → '공익광고 주제'를 '정해진 주제로 고정'으로 바꾸세요.

## 4-2. 패들렛에 올릴 글 한 번에 복사

학생 화면의 **[패들렛에 올리기]** 를 누르면 문장을 고르는 칸과 함께 패들렛 글 미리보기가 나오고, `한 번에 복사하기` 한 번으로 패들렛 글 칸에 붙여 넣을 수 있습니다.

- 기본 양식은 `광고문구 / 문법 조건(성분 + 짜임) / 주제` 세 줄입니다. 이름과 번호는 글 제목으로 따로 들어가므로 본문에는 넣지 않습니다. (예전에 양식을 직접 바꿔 저장했다면 [설정·시험]에서 `기본 양식으로`를 눌러 저장하세요.)
- 양식은 `[설정·시험]` → **패들렛 글 양식**에서 바꿀 수 있습니다. `{이름} {광고문구} {문법조건} {성분조건} {짜임조건} {주제} {학번} {반}` 자리에 학생 내용이 들어가며, 미리보기로 바로 확인됩니다. `기본 양식으로`를 누르면 되돌아갑니다.
- 포스터 그림은 글에 들어가지 않습니다. 학생이 패들렛에서 이미지를 따로 첨부해야 합니다.
- 양식을 바꾸면 학생 화면에 15초 안에 반영됩니다.

## 4-3. 패들렛 내 방에 바로 올리기

학생이 [패들렛에 올리기]에서 **[패들렛에 올리기]** 를 누르면, 같은 양식의 글이 그 학생 번호의 패들렛 섹션에 올라갑니다. 패들렛 유료 구독의 API 키가 필요하고, 글은 선생님 계정 이름으로 올라가고, 제목은 `번호 이름`입니다.

올린 직후 학생 화면에 **[포스터 프롬프트 만들기 →]** 가 나옵니다. 누르면 방금 올린 문장이 선택된 포스터 화면으로 넘어가고, 프롬프트를 만들어 [복사하기]를 누르면 **[내 패들렛 방 열기 →]** 가 강조되어 바로 방으로 가서 그림을 올릴 수 있습니다. (포스터 기능이 켜져 있을 때)

설정 (`설정·시험` → **패들렛 연결**):
1. 패들렛의 개발자 설정에서 만든 **API 키**를 입력합니다. 키는 이 컴퓨터의 data 폴더에만 저장됩니다.
2. **반**을 고르고, 그 반 패들렛의 **보드 ID**(`board_…`)를 넣습니다.
3. **번호별 섹션 ID·소회의실 링크**를 붙여 넣습니다. 한 줄에 `번호  sec_…  https://padlet.com/…` 형식입니다(섹션 ID 또는 링크 중 하나만 있어도 됩니다). 섹션 ID만 있으면 '바로 올리기', 링크가 있으면 '내 패들렛 방 열기' 버튼이 나옵니다.
4. `저장` 후 `연결 시험`으로 키와 보드 ID를 확인합니다(글은 올리지 않습니다).

동작:
- 올릴 곳은 서버가 **학생의 번호**로 정합니다. 학생이 다른 번호의 방에 올릴 수 없습니다.
- 문법 조건을 맞힌(또는 선생님 확인 중인) 문장만 올릴 수 있고, 같은 문장은 두 번 올라가지 않습니다(`다시 올리기`로만).
- 글의 양식은 `패들렛 글 양식`을 따릅니다. 제목은 `번호 이름`입니다.
- 패들렛 API는 이미지 파일 올리기를 지원하지 않아, 포스터 그림은 학생이 **내 방에서 이어서** 올립니다. 이미지가 인터넷 주소(https://)로 있으면 입력칸에 붙여 넣어 링크로 같이 올릴 수 있습니다.
- 오류가 나면 학생에게는 안내 문구가, 교사 화면 '패들렛 연결'에는 최근 오류가 표시됩니다.

## 5. AI 판정에 대해

- **AI 없이 쓰기**: `[설정·시험]`의 `판정 방식`을 'AI 없이 선생님이 직접 판정'으로 바꾸면 API 키와 비용이 필요 없습니다. 학생은 조건을 받아 문장을 제출하고 "선생님이 확인해 줄 거예요"라는 안내만 봅니다. 선생님이 `[제출 모아보기]`(기본 필터 `교사 확인 필요`)에서 각 문장에 `문법 정답/문법 오답`, `주제 적절/부적절`, 피드백을 달면 학생 화면에 15초 안에 나타납니다. 판정하면 `교사 확인 필요` 목록에서 빠지므로 남은 것만 이어서 보면 됩니다. 언제든 다시 AI 방식으로 바꿀 수 있습니다.

- AI는 **문장 성분, 문장의 짜임, 완결된 한 문장**만 판정합니다. 공익광고 주제와의 관련성은 판정하지 않습니다(주제는 예시 문장을 만들 때만 참고합니다).
- 학교문법 기준으로 판정하지만 **경계가 애매한 문장은 틀릴 수 있습니다.** (예: 서술절과 보어, 관형사형 어미가 붙은 말이 관형절인지 아닌지)
- AI가 확신하지 못하면 자동으로 '교사 확인 필요'에 올라옵니다. 수업 중에 이 목록을 가끔 확인해 주세요.
- 수업 전에 **[설정·시험]** 의 '판정 시험해 보기'로 몇 문장을 직접 넣어 보세요. 판정 결과가 기대와 다르면 알려 주세요. 기준을 고칠 수 있습니다.
- AI에는 **조건과 문장만** 보내고, 학생의 이름과 학번은 보내지 않습니다.
- AI가 연결되지 않으면 학생에게는 '선생님께 전달했어요'라고 보여 주고 기록은 '판정 대기'로 남습니다. 나중에 **[제출 모아보기]** 에서 `판정 대기 모두 AI로 판정` 을 누르면 한꺼번에 판정합니다.

## 6. 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 학생이 주소로 들어오지 못함 | 선생님 컴퓨터와 같은 와이파이인지 확인하세요. 방화벽에서 '액세스 허용'을 누르지 않았다면 `Windows 보안 > 방화벽 > 앱 허용`에서 Node.js 를 허용하세요. |
| 그래도 접속이 안 됨 | 학교 와이파이가 기기끼리의 접속을 막는 경우가 있습니다(AP 격리). 선생님 휴대폰 핫스팟에 선생님 컴퓨터와 학생 기기를 함께 연결해 보거나, 학교 정보부서에 문의하세요. |
| 비밀번호를 잊음 | 이 폴더의 `.env` 파일을 메모장으로 열면 `TEACHER_PASSWORD=` 뒤에 있습니다. 바꾸고 프로그램을 다시 켜세요. |
| `API 키가 올바르지 않아요` | 키를 다시 복사해서 붙여 넣고 [연결 시험]을 눌러 보세요. |
| `포트 3000 을 이미 사용 중` | 프로그램이 이미 켜져 있는지 확인하세요. 아니라면 `.env` 의 `PORT=3000` 을 `PORT=3001` 처럼 바꾸세요. |

## 7. 자료 보관과 정리

- 명단, 학생 기록, 설정은 모두 이 폴더의 `data` 폴더에 저장됩니다. **`data` 폴더를 복사해 두면 백업**이고, 다른 컴퓨터에 옮길 때도 이 폴더를 그대로 가져가면 됩니다.
- API 키는 `data/settings.json` 에 저장됩니다. `data` 폴더를 남에게 주지 마세요.
- 이 프로그램은 인터넷 서비스에 공개된 것이 아니라 선생님 컴퓨터에서만 돌아갑니다. 프로그램을 끄면 학생은 접속할 수 없습니다.
- 학번·이름·문장 기록은 학생 개인정보입니다. 학교의 개인정보 지침에 맞게 보관하고, 학기가 끝나면 `[명단 관리]` 에서 기록을 지우거나 `data` 폴더를 정리하세요.

## 8. 조건을 바꾸고 싶을 때

선생님 화면의 **[조건 관리]** 탭에서 직접 고칠 수 있습니다. 파일을 열 필요가 없습니다.

- **문장 성분 출제 방식**: 기본은 *문장 성분 7가지(주어·서술어·목적어·보어·관형어·부사어·독립어) 중에서 무작위로 뽑기*입니다. 학생마다 "목적어·관형어·부사어가 모두 있는 문장"처럼 받습니다. 한 번에 들어갈 **성분 개수(최소~최대)** 와 출제할 성분(체크)을 정할 수 있습니다. 보어와 목적어는 한 문장에 함께 넣기 어려워 함께 뽑지 않습니다. 예전처럼 직접 만든 조건 목록을 쓰려면 `미리 정한 조건 목록에서 뽑기`를 고르세요.
- **문장 성분 조건 / 문장의 짜임 조건**: 항목을 눌러 이름, 난이도(쉬움/기본), 학생에게 보여 줄 안내 문장, 예시, AI 판정 기준을 고칠 수 있고, `+ 조건 추가`로 새로 만들 수 있습니다.
- **공익광고 주제**: 이름을 눌러 바로 고치고, 여러 주제를 한 줄에 하나씩 붙여 넣어 한꺼번에 추가할 수 있습니다.
- **출제하기 체크를 끄면** 그 조건은 학생에게 나가지 않습니다(지우지 않고 잠시 빼 두기). 켜 둔 항목은 종류마다 최소 1개 있어야 합니다.
- 반드시 **[저장]** 을 눌러야 적용됩니다. 저장하면 새로 조건을 받는 학생부터 바뀌고, 이미 받은 조건은 그대로 이어서 풀 수 있습니다.
- **AI 판정 기준**은 학생에게 보이지 않고 AI만 읽습니다. '무엇이 있어야 정답인가, 무엇은 인정하고 무엇은 안 되는가'를 구체적으로 적을수록 판정이 정확해집니다. 비워 두면 안내 문장으로 자동 작성됩니다. 새 조건을 만든 뒤에는 **[설정·시험]의 '판정 시험해 보기'** 로 정답·오답 문장을 몇 개 넣어 확인해 보세요.
- 조건을 지워도 이미 쌓인 기록에는 그때의 조건 이름이 그대로 남습니다. 다만 지운 조건으로 받아 둔 학생의 문제는 제출할 때 '새 조건을 받아 주세요'로 안내됩니다. 수업 중에는 지우기보다 끄기를 권합니다.
- `기본 조건으로 되돌리기`를 누르면 처음 상태로 돌아갑니다.
- 수정 내용은 `data/conditions.json` 에 저장되므로 `data` 폴더를 백업하면 함께 보관됩니다.
